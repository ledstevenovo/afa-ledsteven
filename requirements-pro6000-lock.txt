# Fully pinned dependency set for the AFA reproduction on an RTX PRO 6000 (Blackwell, sm_120).
#
# Why this file exists in addition to requirements-pro6000.txt:
#   * requirements.txt pins torch==2.3.0+cu121 and xformers -> that build has no sm_120
#     kernels and cannot run on this GPU.
#   * requirements-pro6000.txt lists only the 13 top-level packages. Installing it alone
#     makes pip backtrack for a long time on the transitive set (numpy/pandas/pyarrow/
#     fsspec/dill/aiohttp ...) and a single stalled connection then kills the whole run.
#     Every transitive pin is spelled out here.
#
# torch is deliberately absent: reuse the base environment's torch 2.8.0+cu128 by creating
# the venv with --system-site-packages (see the commands below). torch 2.8.0 ships the
# sm_120 kernels this card needs; do not let anything downgrade it.
#
#   python3 -m venv --system-site-packages .venv
#   .venv/bin/python -m pip install -U pip
#   .venv/bin/python -m pip install -r requirements-pro6000-lock.txt
#
# Mirror note for this box: huggingface.co is unreachable (use HF_ENDPOINT=https://hf-mirror.com);
# mirrors.aliyun.com/pypi returns HTTP 403 and the tuna CDN drops every connection at ~18 MB,
# so index-url below points at the Huawei mirror (measured 4.9 MB/s, completes large wheels).
# Add --resume-retries 30 if your pip is >= 25.1 so a dropped connection resumes instead of
# restarting.
#
#   --index-url https://repo.huaweicloud.com/repository/pypi/simple
